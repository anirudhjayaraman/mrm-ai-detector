## Vendor Model Assessment: Commercial Real Estate Default Model

### Background

The Bank uses a third-party commercial real estate (CRE) default model licensed from an external vendor to estimate probabilities of default for income-producing CRE loans. The model is used for credit decisioning, risk rating, and as an input into CECL loss estimates. Consistent with SR 11-7, vendor models are subject to the same validation standards as internally developed models, adjusted for the limited access to proprietary information.

### Vendor Documentation Review

The vendor provided a methodology document, a validation summary, and annual performance reports. The documentation describes the model as a loan-level logistic regression using property-level variables (debt service coverage ratio, loan-to-value, property type, and occupancy) and market-level variables (regional vacancy rates and cap rate spreads).

While the documentation provides a reasonable overview of the methodology, it lacks detail in several important areas. Specifically, the vendor has not disclosed the full set of coefficients, the composition of the development dataset, or the results of out-of-time testing. This limits the Bank's ability to fully assess the conceptual soundness of the model.

### Testing Performed

Given the limitations of the vendor documentation, the validation team placed greater reliance on outcomes-based testing using the Bank's own data:

- **Discriminatory power:** Using 2,140 CRE loans with 87 observed defaults between 2015 and 2023, the model achieved an AUC of 0.74. This is acceptable but lower than the 0.81 reported by the vendor on its industry dataset.
- **Calibration:** The model overpredicted defaults for multifamily properties and underpredicted defaults for office properties, particularly in the 2022–2023 period. Observed office default rates were 2.3 times the predicted rate.
- **Benchmarking:** The validation team developed a simple challenger model using the Bank's data. The challenger achieved comparable discriminatory power, suggesting that the vendor model does not add significant predictive value beyond the core variables.

### Assessment

The model provides a reasonable basis for rank-ordering CRE credit risk, but its calibration is not well aligned with the Bank's portfolio, particularly for office properties, where structural changes in demand following the pandemic are not adequately reflected. The limited transparency of the vendor model is a significant constraint on effective challenge.

### Recommendations

1. Apply a calibration overlay for office properties until the vendor delivers an updated model.
2. Request additional documentation from the vendor, including out-of-time performance results and segment-level calibration.
3. Consider adopting the internal challenger model as a benchmark in ongoing monitoring.
