# Changelog

## 1.1.0 (2026-10-22)

Re-scoped after testing on partially AI-written documents.

- **Provenance hints.** Each scan now also reports traces that AI tools leave in
  files, independent of writing style: Word files generated by `python-docx`,
  non-breaking hyphens and narrow spaces in volume, `utm_source=chatgpt.com`
  links, `oaicite` / `turnNsearchN` / `【N†source】` citation markers, chat-style
  openers and assistant offers, template placeholders, "Generated on" stamps.
  Reported separately; they never change the probability. No hint fires on any
  of the 624 human benchmark documents.
- **Non-prose is no longer scored.** Tables flattened by PDF extraction, lists of
  figure captions and software listings are shown but excluded from flags and
  from the AI share; they had produced spurious AI flags.
- **Mixed-authorship benchmark.** `benchmarks/build_mixed.py` builds documents in
  which an assistant polishes, rewrites, writes from notes, continues or
  summarises parts of real pre-2022 MRM text, with every word labelled (local
  Qwen2.5-7B / Llama-3.1-8B / Gemma-2-9B via MLX, Claude, or any OpenAI model
  with your own API key). `benchmarks/eval_mixed.py` measures AI-share accuracy
  on them and on the public APT-Eval and MixSet benchmarks.
- **Recalibrated** both shipped models with the mixed documents (training-split
  sources only).
- **Documented limit:** current frontier models writing from the author's own
  material are not detected by this tool or by any other detector tested,
  including a full-size (7B) Binoculars. See the README benchmark summary.

## 1.0.0 (2026-10-08)

First public release.

- Zero-dependency detector for AI-generated text in model risk documentation:
  domain-evidence, LLM-marker, stylometric and information-theoretic features
  combined in a calibrated logistic model, with per-segment scores, bootstrap
  confidence intervals and mixed-authorship detection.
- Optional `[lm]` ensemble: Binoculars and Fast-DetectGPT (zero-shot) plus the
  HC3, Fakespot and Desklib classifiers.
- Inputs: `.txt .md .rst .docx .pdf .html .eml .msg` and images. OCR is built
  in on macOS (Apple Vision); RapidOCR elsewhere.
- `mrm-detect baseline` compares a document with the author's own earlier
  writing.
- `mrm-detect train` / `evaluate` calibrate on an organisation's own documents.
- Reproducible benchmark against nine open-source detectors and three free web
  detectors (see `benchmarks/`).
